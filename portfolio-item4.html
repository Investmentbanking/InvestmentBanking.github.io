Scholar++ Search Engine

Full-Stack Scholarly Search & Analytics Platform

Project Overview

Scholar++ is a full-stack scholarly search engine built with Python and Django, designed to make academic information easier to discover, explore and analyse.

The platform integrates with the OpenAlex API to search scholarly content including works, authors, concepts, venues and institutions. It provides both simple keyword search and more advanced relationship-based discovery between scholarly entities.

Scholar++ also includes authentication, bookmarking, search history, analytics and detailed entity pages, creating a complete research discovery experience beyond a standard keyword search tool.

Key Features

Advanced Scholarly Search

Supports both standard keyword searches and advanced searches based on selected scholarly entities and their relationships.

Asynchronous API Integration

Uses aiohttp and asyncio to retrieve scholarly information from the OpenAlex API asynchronously, including concurrent operations during more complex searches.

Relationship-Based Discovery

Advanced search can explore relationships between authors, works, citing works, co-authors and publication sources.

Detailed Entity Pages

Dedicated information pages display scholarly data, statistics and relationships for works, authors, concepts, venues and institutions.

Authentication & Bookmarking

Users can create accounts, log in using standard credentials or GitHub OAuth, and bookmark scholarly entities for later access.

Search History

Previously accessed scholarly entity pages are stored, allowing users to quickly return to earlier research and discoveries.

Architecture

Scholar++ separates search behaviour, external API interaction, authentication, analytics and entity presentation across dedicated application modules, keeping responsibilities organised throughout the system.

Entity-Based Search

Search functionality distinguishes between scholarly entity types such as authors and works, allowing search behaviour to adapt depending on the selected entity.

Reusable Search Logic

Shared asynchronous search functions handle common behaviour while allowing entity-specific lookup functions and result formatting to be supplied.

Concurrent API Requests

Independent API operations can run concurrently using asyncio.gather, reducing unnecessary sequential waiting during advanced search operations.

Validation & Filtering

Custom Django form validation checks entity selections, search types and date ranges before advanced search requests are processed.

Challenges & Design Decisions

Modelling Relationships Between Scholarly Entities

Advanced search needed to support more than direct keyword matching. Search flows were designed to move between related authors, works, citing works, co-authors and publication sources.

Handling External API Requests Efficiently

Scholar++ depends heavily on external scholarly data, so asynchronous requests and concurrent operations were used where appropriate to reduce unnecessary waiting during complex searches.

Keeping Search Inputs Valid

Advanced search supports different combinations of entities, search modes and date filters. Custom validation prevents invalid combinations from being submitted to the search layer.

Presenting Complex Academic Data

Scholarly information can contain large amounts of interconnected data. Dedicated information pages, analytics and visualisations help organise this information into a clearer and more accessible interface.

Advanced Search

Scholar++ goes beyond standard keyword matching by allowing users to discover scholarly content through relationships between authors, works and publication sources.

Author → Citing Works

Finds works published by selected authors alongside scholarly works that cite their publications.

Author → Related Sources

Finds works published in sources where selected authors have previously published.

Work → Co-Author Discovery

Identifies authors associated with selected works and retrieves additional works connected to their co-authors.

Work → Source Relationships

Finds authors of selected works alongside other authors who have published within the same publication sources.

Analytics & Visualisation

Scholar++ includes analytical functionality designed to make scholarly information easier to understand and compare.

pandas is used for data processing and analytics, while Chart.js provides graphical visualisations within the application interface.

Authentication & User Features

Authentication is implemented using django-allauth. Users can access the platform through traditional account credentials or external GitHub OAuth authentication.

Authenticated users can bookmark scholarly entities and access previously viewed entity pages through the application's history functionality.

Deployment

Scholar++ was deployed on a Raspberry Pi and made publicly accessible through the scholarplusplus.org domain.

The original Raspberry Pi deployment is no longer active, so the application currently needs to be run locally for demonstration.
